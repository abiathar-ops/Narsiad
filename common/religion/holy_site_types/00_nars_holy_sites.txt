# Holy sites of the Selian faith.
#
# 1.20 format: 'character_modifier' (faith-wide while held) was split in two, and 'flag' became 'parameters':
#   county_holder_character_modifier - the holder of the site's county, if of the faith (regular and eminent sites)
#   faith_character_modifier         - every character of the faith, only while the site is one of the faith's eminent sites
# Each site carries both, with the 1.19 values, so promoting or demoting a site in play works.
# Which sites start eminent is set in common/religion/faith_types/00_nars_faiths.txt.
#
# 'baghdad' and 'niani' are no longer redefined here: they are base-game holy sites and the Selian faith uses those definitions.
